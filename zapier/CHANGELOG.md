# Changelog

What each version changes for a Zap's user; `npx zapier-platform promote <version>` sends the version's section to
Zapier, which requires one.

## 1.0.0

The first version: four actions, Look up a phone number, Verify an email address, Look up an IP address and Assess
the risk of an identity, and one trigger, File completed. The connection takes a ProofTell API key: a `pt_test_` key
is the free sandbox, a `pt_live_` key spends the account's balance.
